# Linux 运行可靠性与容器部署

[English](../en-US/linux-reliability.md)

## 流式响应

Agentic 流按原索引和具体内容类型建立映射，按首次出现顺序分配索引，防止交错的文本、推理和工具调用被错误合并。工具参数保持原样，异常参数仍须通过既有校验。这不解决网络断连或服务商余额不足。

## 反向代理

MCP SSE 只信任直接连接来源位于 `server.trusted_proxies` 的 `X-Forwarded-Proto`。填写实际代理 IP 或窄范围 CIDR；代理必须覆盖该请求头为 `http` 或 `https`。重复请求头、逗号分隔链和其他协议被忽略，空信任列表不接受转发头。修改后重启生效。独立 MCP 监听器仍为 HTTP，公网 TLS 由代理终止；此功能不处理转发主机名或路径改写。

## 重启恢复

启动工作协程前，以事务将遗留运行中的批量子任务标为失败；有待执行子任务的运行队列转为暂停，否则结束并保留中断说明。助手占位消息记录错误事件。不会自动重做任务，也不会覆盖已完成回复或改写待办任务。恢复失败时停止启动。一个数据库只允许一个应用实例使用。升级前备份数据库；此变更更新已有任务状态，不增加表结构。恢复执行前应检查已产出的部分结果。

## Docker Compose

需要 Linux Docker Engine 与 Compose 插件，在仓库根目录执行：

```sh
docker compose config --quiet
docker compose up -d --build
docker compose ps
docker compose logs --tail 100 cyberstrike
```

默认访问 `http://127.0.0.1:8080`，生产环境通过 TLS 反向代理访问。容器以 UID/GID 10001 运行，移除额外 capabilities，并启用 no-new-privileges。需要原始套接字权限的扫描工具不属于此默认部署配置；镜像也不包含所有第三方工具依赖。

首次启动生成 `/app/runtime/config.yaml`，容器模板关闭内部 TLS，并使用绝对资源路径；已有配置不覆盖。通过设置页面或配置中的环境变量引用填写供应商凭据。不要公开配置及初始密码日志。配置挂载整个目录以支持设置的原子保存，不要替换成单文件挂载。数据、日志、上传、工作目录、知识库和技能使用独立命名卷。自定义角色和工具需单独挂载，否则使用随镜像升级的内置文件。

```sh
# 一致性备份前停止服务。
docker compose stop
# 使用现有备份工具备份命名卷，然后启动。
docker compose start
```

升级时不要执行 `docker compose down -v`，该命令会删除持久化卷。回滚应先停机，再恢复匹配的镜像、配置及数据库备份；数据库恢复会丢弃备份后的记录。若启用应用 TLS 或更改端口，需相应调整健康检查。

容器工作流构建并冒烟验证 Linux amd64 镜像。发布稳定 GitHub Release 时，确认提交属于 main 后，可向本仓库 GHCR 命名空间推送版本镜像；手动运行只验证，PR 不发布，不会自动部署测试机。当前不发布浮动 latest 标签，也不宣称已验证 arm64。

## 知识库索引续建与恢复

索引会先完成全部分块的嵌入，再在同一个 SQLite 事务内替换该条目的向量和完成标记。
供应商错误、取消、写入失败或数据库正文在生成期间变更，都保留旧向量。
因此，替换成功前，检索仍可能返回之前的内容。

新增 `knowledge_index_state` 表保存条目 ID、来源与配置摘要、分块数、模型和维度。
修改正文等字段会使标记失效。续建检查缺块、重复或越界编号以及模型/维度元数据；
模型、端点、分块配置和子索引变更会触发重建。启用 `prefer_source_file` 时，续建读取
源文件并比较内容；读取后的文件改动在下次续建识别，不与 SQLite 形成跨文件事务。

旧索引没有完成标记，首次手动续建会重建，可能消耗嵌入额度。升级不会自动启动付费重建。
失败条目可再次续建；空内容记录为有效的零分块状态。这是索引完成性检查，并非逐个向量的
密码学完整性校验。升级前应停机备份知识库、会话数据库和配置。

## 自动化升级回归

Linux 容器工作流构建当前镜像和固定的 EV v1.7.22 基线镜像。
`tests/container/upgrade_rollback.py` 通过真实登录和设置 API 保存配置与会话，携带全部
七个持久卷升级并重建容器，再恢复停机卷快照并启动旧镜像，核验 UID 10001、配置和数据。
测试使用生成的独立数据，不调用模型服务；结束后清理临时容器与卷，不打印初始密码。
覆盖范围为指定基线与 Linux amd64，不代表已验证所有历史版本的迁移。

```sh
python3 tests/container/upgrade_rollback.py \
  --current cyberstrike-ai-ev:check --baseline cyberstrike-ai-ev:baseline
```
