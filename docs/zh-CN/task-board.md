# 任务看板、异常与证据关联

[English](../en-US/task-board.md) · [执行过程](execution-view.md)

侧栏打开 **AI 执行过程**。默认先展示异常摘要和“计划 → 执行 → 验证”任务看板；Swarm 图位于下方，默认折叠，展开后才加载图形库及 GPU 资源。工具异常按所选轮次、工具和状态汇总；审批及其他异常仅代表当前事件页记录，可能已在其他页面处理。点击“查看来源”定位对应记录，跨页结果通过原有锚点接口加载，不自动重复执行。

## 状态同步

页面可见且自动同步开启时，运行中每 10 秒、空闲每 30 秒刷新，以发现后续启动的任务。默认跟随最新轮次；主动选择历史轮次后固定选择，点击“最新轮次”恢复跟随。清空轮次选择时仍同步任务看板；重新登录后会恢复当前执行页面。隐藏页面或离开页面取消读取，连续三次读取失败后暂停并等待手动刷新。

刷新历史页后若没有助手轮次，会同步清空轮次事件、摘要、图形筛选及旧轮次的来源选择，不继续展示已删除轮次的动作；独立保存的任务看板保留并继续同步。

任务原始状态仍由 Agent 保存。完成任务进入验证列并标记“待核验”；执行前持久化真实运行边界，运行中及停止／重启后都过滤旧任务文件；最近一次执行中未完成的任务标明暂停。旧会话若未记录边界则明确标记历史任务，不冒充某次执行快照。文件更新时间和半写入提示用于说明同步情况，不依据旧时间戳推断运行已经结束。半写入期间保留上次完整看板，刷新不收起已展开卡片。

## 关联证据

展开任务后点击“关联证据”，从当前事件页工具结果中选择，或搜索同项目／会话内当前有权读取的项目事实、漏洞记录。项目事实和漏洞每次搜索最多 25 条。关联是明确选择的支持材料，不自动推断关系、不自动判定验证通过。可打开来源复核或解除关联；解除不会删除原始证据。关联写入数据库并跨服务重启保存。任务 ID 与标题共同确定身份：状态更新保留关联，改名或同 ID 不同标题不继承旧关联。

列表、搜索和写入均重新核对来源权限与资源范围。读取需要 `chat:read`，新增需要 `chat:write` 及来源读取权限，解除需要 `chat:delete`。工具结果只能来自当前会话；事实／漏洞限制在同项目，无项目时漏洞限制同会话。事实还须核对来源会话和所关联漏洞的读取权限。来源被删除或无权读取时，不返回其名称、ID 或隐藏关联数量。响应和审计详情不复制工具输出、事实正文和漏洞证据。

事实搜索在 SQL 中先核对来源权限，再限制为 25 条，避免较新的隐藏记录挤掉较早的可读结果。所有证据接口与最近看板共用当前／已保存的运行边界；被边界排除的旧任务在读取、搜索、新增和解除时返回 404，历史关联仍保存在数据库中。

漏洞候选也在分页前使用与来源读取一致的权限范围。无绑定项目时，仅接受直接属于当前会话的漏洞；仅在当前会话出现过观察记录的漏洞仍可在普通漏洞列表查看，但不占用证据选择器名额。

新增关联时，在同一事务中清理已确认来源不存在的悬空关联，再检查容量；仅因当前用户权限不足而不可见的有效来源不会被删除。

## 接口和存储

接口详情及 JSON 示例见[英文接口表](../en-US/task-board.md#apis)。路径前缀为 `/api/conversations/{id}/plan-tasks/{taskId}`：

| 方法和路径 | 用途与参数 | 成功结果 |
| --- | --- | --- |
| GET `/evidence` | 当前可读取的显式关联 | `items`、`taskIdentity` |
| GET `/evidence-sources` | `kind=project_fact` 或 `vulnerability`，可选 `search`（最多 400 字节） | 最多 25 条来源元数据 |
| POST `/evidence` | JSON：`kind`、`sourceId`、`taskIdentity`；最多 4 KiB | `id`；重复提交幂等 |
| DELETE `/evidence/{linkId}` | 解除当前任务的某条关联 | `removed: true` |

200 成功；400 参数错误；401 未登录；403 权限或资源范围不足；404 任务／关联／来源不可用；409 任务身份变化、半写入或超出每任务 20 条关联限制；500 存储失败且只返回通用提示。新增／解除操作保留审计记录。最近看板响应增加 `incomplete`、`observedAt`、`runStartedAt`、`boundaryKnown`，任务增加 `identity`、`updatedAt`、`runtimeStatus`。

新增 SQLite 表 `plan_task_evidence`：`id` 主键，`conversation_id` 会话外键（删除会话级联），`task_id`，`task_identity`（任务 ID／标题的 SHA-256），`kind`，`source_id`，`created_at`。会话／任务／身份／来源类型／来源 ID 的联合唯一索引负责去重及范围查询，不保存原始证据正文。任务文件和来源记录不因关联而改变。另有 `conversation_plan_runs` 表保存最近一次运行的 `conversation_id`（主键及级联外键）、`run_id`、UTC `started_at`；持久化不占用任务管理器全局锁，写入失败则不开始该次执行。

Windows/Linux 使用同一实现。升级前备份数据库，等待活动任务完成后再重启，同步服务端、HTML、脚本、样式和语言文件。表在启动时自动创建，无新增运行配置或模型请求。回滚时保留数据库，旧程序会忽略新增表。测试使用临时数据库与模拟证据，不请求真实模型和公网目标。
